# Terraform AWS Project

This project contains Terraform configuration files for creating AWS resources.

## Files

- `provider.tf` - Configures the AWS provider.
- `main.tf` - Contains the main Terraform resources.
- `var.tf` - Contains Terraform variables.
- `.gitignore` - Specifies files that Git should ignore.

## Prerequisites

- AWS Account
- Terraform installed
- AWS credentials configured

## Terraform Commands

```bash
terraform init
terraform plan
terraform apply


terraform destroy
